# 2026-11-03 工程整理记录

## 目标

从包含 Noesis、研究实验和大量本地产物的开发工作区，提取可继续维护的插件工程。目标仓库原有 `ingegames` 分支、Git 历史和 remotes 保持不变；此次没有提交、推送或重写历史。

旧工作区保留为私有历史对照，不对其源码和游戏输入做覆盖迁移。

## 保留

- 四个现行核心插件模块，以及 GUI 部件预设。
- 可复用的编码、骨架、模型与服装测试。
- 为真实样本回归必需的最小 PAK/骨架读取适配层。
- 不绑定个人路径的 FBX 结构与蒙皮检查工具。
- 有明确适用范围的格式规则、研究方法、失败记录和案例材料摘要。

## 不迁入发布树

- Noesis 运行时、宿主 API 模块、第三方 DLL 和不相关插件。
- 游戏资源与导出的 FBX/贴图/场景。
- 转储、反编译数据库、屏幕录制、截图和旧验证产物。
- 大量一次性研究探针、旧备份目录及依赖固定个人目录的启动器。
- `NDTextureHashes.json`、`NDRawDataStarts.json` 等派生缓存。
- 个人配置、企业邮箱和本机用户目录。
- 手工维护的重复 HTML 页面，以及模型署名尚未确认的推广稿。

可复用的回归测试属于工程代码，不是游戏测试资源，因此保留在 `tests/`。真实样本通过环境变量从仓库外读取。

## 代码清理

删除的动画旧原型：

- `decodeFramePositions()` / `decodeFrameRotations()`：旧单槽与位宽三等分路径。
- `readConstantRotations()`：重复解析第 0 槽并构造已不使用的中间状态。
- `decodeConstantPositions()` 及量化邻域工具：扫描绑定平移猜测布局的早期研究代码。
- 不再使用的半精度编码器和仅供上述原型使用的绑定平移读取器。
- 无实际验证语义的 `isFullyDecoded` 标志与过时诊断。
- 内部 `animJointNames` 按名字跨骨架映射接口；普通构建默认不启用 additive。
- 主插件内不执行的多行实验代码块，以及没有标签的临时偏移打印。

保留当前分段解码、骨架数学、原始蒙皮数据处理和有用途的 `-ndlegacyhelpers` 对照开关。不是把所有带有 legacy 名称的功能一律删除。

配置与接线修正：

- 增加 `inc_nd_config.py`、`NDConfig.example.json` 与环境变量配置。
- 修正 Part II PC 游戏识别及 PS4 根目录提取。
- 部件清单使用 `${TLOU2}/...`，不再携带个人绝对路径。
- 增加 `-ndgame` 与 `-ndrebuildtextures`；缓存可由本地字典包重建。
- 移除指针错误路径中的未定义崩溃占位名，改为明确异常。
- 修复资源缓存文件句柄和旧可变默认参数，保持改动范围可验证。
